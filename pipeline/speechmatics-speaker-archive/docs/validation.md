# Проверка сборки

Дата локальной и CI-проверки опубликованного снимка: 2026-08-11.

Проверено:

- импорт и компиляция всех Python-модулей;
- 21 автоматический тест;
- FFmpeg: WAV → FLAC 16 кГц mono;
- обнаружение и защита от повторного добавления WAV;
- конфигурация Speaker Identification и фильтрация voice ID по модели/языку;
- сборка реплик из пословного JSON;
- запись `video_speakers`, `utterances`, `words` в SQLite;
- полный mock-проход очереди от папки до готового видео;
- HTTP-страницы dashboard/profiles/sources/videos/settings/health;
- экспорты RAW JSON, JSON, CSV, SRT и согласованная копия SQLite.
- экспорт VTT и TXT;
- проверка публичного дерева на реальные ключи, runtime-файлы и приватные пути;
- FastAPI health smoke-test с временной SQLite-базой;
- GitHub Actions для повторения secret scan и тестов на каждом изменении пайплайна.
- сохранение общей паузы при account-level ошибке и её явное снятие оператором.

Не выполнялось:

- реальная отправка в Speechmatics SaaS, потому что в среде сборки не было пользовательского API-ключа;
- сборка Docker-образа, потому что Docker CLI отсутствовал в среде сборки. `docker-compose.yml` проверен как корректный YAML.

REST-интеграция реализована напрямую по Batch API, чтобы удалённый `job_id` и все переходы состояния явно сохранялись в локальной БД.
